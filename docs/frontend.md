# Фронтенд «слово.»

Отдельное приложение Vue 3 + TypeScript + Vite находится в `web/`. Код Go в `stt-service/` фронтенд не меняет. Браузер отправляет медиа только своему API; внешних шрифтов, аналитики и облачного распознавания нет.

## Локальный запуск

Нужен Node.js 22.18+ (проверено на 22.23.3).

```bash
cd web
npm ci
npm run dev:demo
```

Открыть <http://127.0.0.1:5173>. Деморежим показывает подготовленный пример, позволяет добавлять записи и проходить состояния очереди. Файлы не отправляются и не распознаются; текст и длительности демонстрационные. Это обозначено в интерфейсе. Демоданные сохраняются в localStorage отдельно от настроек рабочего режима.

Для настоящего API:

```bash
cd web
npm run dev
```

Запросы `/api/*` проксируются на `http://127.0.0.1:8080`. Другой адрес можно задать через `STT_API_PROXY` в `web/.env.local` (образец — `web/.env.example`). Корневой `.env` с SSH-параметрами Vite не загружает. Никогда не помещать пароль или SSH-параметры в переменные `VITE_*`.

Рабочий режим не подменяет ошибки подключения демоданными. Если Go API ещё не готов, будет показано отсутствие связи.

## Что реализовано

- Адаптивный интерфейс на русском для компьютера и телефона.
- Выбор файла и drag-and-drop; по одному файлу за отправку.
- Английский язык фиксирован, максимум 600 секунд включительно.
- Проверка пустого файла, поддерживаемого расширения и доступной браузеру длительности.
- Если браузер не умеет прочитать формат или длительность, проверку выполняет сервер. Он всегда обязан проверить фактическую длительность через ffprobe: UI не является защитой от обхода лимита.
- Отдельный прогресс передачи файла; после 100% — ожидание серверной проверки.
- Список заданий с поиском и фильтрами, обновление каждые 3 секунды (7 секунд при отсутствии связи).
- Все шесть состояний: queued, preparing, transcribing, completed, failed, cancelled.
- Отмена обработки, повтор неудачной/отменённой записи, удаление завершённой записи с подтверждением.
- Полный текст и сегменты с таймкодами, копирование, экспорт TXT/SRT/JSON в браузере.
- Безопасный вывод текста как текста, без `v-html`.
- Восстановление выбранной записи после обновления страницы; в рабочем режиме задания и текст загружаются из API, а не из localStorage.

Остановка передачи файла не гарантирует отмену уже принятого сервером задания. Интерфейс обновляет список и предлагает отменить такое задание отдельно. POST загрузки автоматически не повторяется, чтобы не создавать дубликаты.

## Структура

```text
web/src/
  api/                 HTTP-клиент, отдельный демоадаптер
  components/          загрузка, список, расшифровка, иконки, статусы
  composables/         очередь запросов, polling, выбор записи и действия
  types/               Job, Transcript, JobsApi
  utils/               проверка медиа, форматирование, экспорт
  views/               композиция рабочего экрана
  styles/              общие стили и адаптивная сетка
```

## Контракт для Go-бэкенда

[OpenAPI](../api/openapi.yaml) — контракт, реализованный Go API и текущим HTTP-клиентом. Если бэкенд выберет другой формат, точка адаптации — `web/src/api/http.ts`.

| Запрос | Результат |
| --- | --- |
| `GET /api/jobs` | `200 { "jobs": [...] }` |
| `POST /api/jobs` | multipart: `file` + `language=en`; `202 Job` |
| `GET /api/jobs/{id}/transcript` | `200 Transcript` |
| `POST /api/jobs/{id}/cancel` | `200 Job` после отмены |
| `POST /api/jobs/{id}/retry` | `202 Job` с тем же ID и состоянием queued |
| `DELETE /api/jobs/{id}` | `204`, пустое тело |

Ошибка: `{ "error": { "code": "duration_exceeded", "message": "Длительность записи превышает 10 минут." } }`.

`Job` использует snake_case. Поля `duration_seconds`, `progress`, `error` присутствуют всегда; неизвестные значения — `null`, а не отсутствующее поле. `progress` — доля реально распознанного аудио от 0 до 1. Даты — RFC 3339, язык — `en`. `filename` содержит только отображаемое имя.

`Transcript`: `{ "language": "en", "text": "полный английский текст", "segments": [{ "start": 0, "end": 5.4, "text": "..." }] }`. Время в секундах, сегменты упорядочены. При отсутствии временных меток допустимо `segments: []`: SRT будет недоступен. Пустой `text` отображается как отсутствие распознанной речи.

Сервер должен сохранять задания независимо от браузера, обрабатывать одну запись за раз, очищать временные файлы при отклонении загрузки и прекращать дочерние процессы при отмене. Активную запись сначала отменяют, затем удаляют. Повтор использует сохранённый исходник; если его уже нет, API возвращает понятную ошибку.

## Сборка и проверки

```bash
cd web
npm run build
npm run test:e2e
```

Результат production-сборки — `web/dist/`. Демокод не включается в обычную сборку. Go должен обслуживать `dist` на `/`, каталог `dist/assets` — на `/assets`, API — на `/api`. Не подменять неизвестные `/api/*` маршруты HTML-файлом. Node.js на Raspberry для обслуживания готового `dist` не нужен.

Браузерные тесты используют Playwright и подменяют только API, без Go-сервера. Они проверяют границы 600 секунд, отправку, серверные ошибки, отмену/повтор/удаление, экспорт, восстановление выбора, безопасное отображение текста, отсутствие скрытого деморежима и мобильную раскладку.

Для тестов можно использовать установленный Chromium через `PLAYWRIGHT_CHROMIUM_EXECUTABLE`; если переменная не задана, используется браузер Playwright (установка: `npx playwright install chromium`). Запуск production-сборки для просмотра: `npm run preview`.


## Хранение истории и очистка

После удаления файлов запись задания сохраняется в SQLite с прежним статусом и
отметкой `removed_at`. Список API исключает такие записи; фронтенд убирает их при
следующем обновлении. Расшифровка удалённого задания возвращает 404, повтор — 409.

Планируемая фоновая очистка запускается раз в сутки для конечных заданий старше
24 часов по `finished_at`. Это поле заполняется для completed, failed и cancelled;
при повторе сбрасывается. Исходник, временные файлы и результат удаляются до
выставления `removed_at`; ошибка удаления оставляет задание для следующей попытки.
Горутина очистки и SQL-методы реализованы; запуск и настройки описаны в [backend.md](backend.md).
