# stt-go-server

Локальная транскрипция английской речи на Raspberry Pi. Поддерживаемая длительность аудио и видео — до 10 минут (600 секунд включительно).

Результат — полный английский текст, без перевода и пересказа. Файлы длиннее лимита должны отклоняться сервером, без автоматической обрезки. Интерфейс остаётся на русском; выбор языка распознавания не требуется.

Бэкенд MVP и Vue-интерфейс реализованы локально: потоковая загрузка, проверка
длительности через ffprobe, очередь SQLite, обработка FFmpeg/whisper-cli,
отмена, повтор, просмотр результата и ежедневная очистка с сохранением истории.
Полный запуск приложения на Raspberry Pi ещё не проверен.

Параметры подключения задаются в локальном `.env` по образцу `.env.example`.
`.env`, аудиопримеры и результаты тестов исключены из Git.

Проверка движка распознавания описана отдельно от приложения: Go-бэкенд, Vue-интерфейс и systemd-развёртывание не являются частью тестового стенда.
